Description
===========

This module handles maquila operational workflows:

* Temporary admission management with customs control
* Export dispatch with traceability to source admissions
* Customs guarantee tracking (bank/insurance/deposit/mortgage)
* TUM 1% tax calculation wizard
* IVA tax credit compensation and transfer wizard
* Fiscal position auto-assignment for maquila purchase/sale orders
* Stock location segregation for maquila operations
* Integration with purchase.order and sale.order
