Plantillas MIS Builder para los informes contables paraguayos:

- **Balance General**: Activo Corriente / No Corriente, Pasivo Corriente / No Corriente, Patrimonio Neto.
- **Estado de Resultados (RG 49/14)**: Ingresos Operativos, Costos, Margen Bruto, Gastos Operativos, Resultados Financieros, Otros Ingresos y Egresos, Impuesto a la Renta, Resultado del Ejercicio.
- **Flujo de Efectivo (Indirecto)**: parte del resultado neto + ajustes de partidas no monetarias y variaciones del capital de trabajo.

Las fórmulas usan los prefijos del Plan de Cuentas RG 49/14:

| Prefijo | Concepto |
|---|---|
| 1.01.* | Activo Corriente |
| 1.02.* | Activo No Corriente |
| 2.01.* | Pasivo Corriente |
| 2.02.* | Pasivo No Corriente |
| 3.* | Patrimonio Neto |
| 4.* | Ingresos Operativos (Ventas) |
| 5.* | Costos / Variación de Inventarios |
| 7.* | Gastos de Personal |

| 10.* | Otros Ingresos |
| 11.* | Gastos Operativos |
| 13.* | Gastos Financieros |

| 19.* | Impuesto a la Renta |

El Balance General muestra el **Resultado del Ejercicio (no asignado)** como el saldo de las cuentas de
resultado todavia abiertas (tipos de cuenta de ingreso y gasto), de modo que Activo = Pasivo + Patrimonio
Neto tambien antes del cierre del ejercicio. En el Pasivo Corriente, 2.01.03.01 son Obligaciones Fiscales
(IVA, Renta, Retenciones), 2.01.03.02 Remuneraciones y Cargas Sociales y 2.01.04 Provisiones.
