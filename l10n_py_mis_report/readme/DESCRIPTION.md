Plantillas MIS Builder para los informes contables paraguayos:

- **Balance General**: Activo Corriente / No Corriente, Pasivo Corriente / No Corriente, Patrimonio Neto.
- **Estado de Resultados (RG 49/14)**: Ingresos Operativos, Costos, Margen Bruto, Gastos Operativos, Resultados Financieros, Otros Ingresos y Egresos, Impuesto a la Renta, Resultado del Ejercicio.
- **Flujo de Efectivo (Indirecto)**: parte del resultado neto + ajustes de partidas no monetarias y variaciones del capital de trabajo.
