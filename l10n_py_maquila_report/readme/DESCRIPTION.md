Reporting for Paraguay's Maquila regime (Ley 7547/2025):

- **CNIME periodic report**: a snapshot of imports, exports, production, waste,
  period-end stock balance, VAN and employment for a program and period. The
  snapshot is compiled by *Generate* and frozen once submitted.
- **Maquila dashboard** (kanban) of active programs.
- **SIFEN legend**: adds the maquila legend (Ley 7547/2025) to the electronic
  document data.
- **SIMEX payload** generation (offline).

The VAN reported here uses the same computation as the MRP VAN wizard, so both
report the same figure for a given program and period.
