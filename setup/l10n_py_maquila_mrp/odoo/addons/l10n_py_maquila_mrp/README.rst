Description
===========

This module extends MRP for Maquila operations:

* BOM extensions with INTN certification and origin type per component
* Builds on OCA mrp_bom_line_net_qty for INTN coefficients
* VAN (National Added Value) calculation wizard
* Waste management with destruction/nationalization/re-export tracking
* Automatic maquila program propagation to production orders
