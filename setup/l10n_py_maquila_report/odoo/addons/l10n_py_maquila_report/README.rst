Description
===========

This module provides reporting and EDI integration for Maquila:

* CNIME periodic report generation (imports, exports, production, waste)
* Dashboard with program KPIs (kanban view)
* SIFEN EDI extension (maquila legend in electronic invoices)
* SIMEX payload generation stub (offline mode)
