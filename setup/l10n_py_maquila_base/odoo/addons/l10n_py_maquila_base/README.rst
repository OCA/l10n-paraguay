Description
===========

This module provides the base data structures for managing Maquila programs
under Paraguay's Law 1064/97. It includes:

* Maquila Program management (types: pura, ociosidad, abrigo, servicio)
* Product lines with INTN certificate tracking
* Integration with OCA Agreement for CNIME contracts
* Integration with OCA Contract for recurring billing
* Automatic expiry alerts via scheduled actions
* Multi-company support with maquiladora flag
