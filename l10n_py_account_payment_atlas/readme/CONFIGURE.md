On a bank account (Contactos > a Company's res.partner.bank, or Accounting
> Configuration > Bank Accounts), enable "Banco Atlas" and fill in:

- Entorno (Testing / Producción)
- Número de cuenta Atlas
- API Key
- Clave privada (PEM) de la aplicación
- Clave pública (PEM) del banco
- Token de autorización (obtenido manualmente del banco, fuera de esta API)

All of these fields are restricted to the Accounting Manager group.
